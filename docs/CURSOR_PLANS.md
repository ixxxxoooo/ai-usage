# Cursor 不同账号类型怎么计算

> 作者：ixxxxoooo

不是所有 Cursor 账号都是「每月 500 次」。应用同时读取两个接口，按账号实际情况选择口径。

## 两种口径

| 口径 | 适用账号 | 数据来源 | 展示 |
| --- | --- | --- | --- |
| 次数制（`requests`） | 旧版 Pro（`gpt-4.maxRequestUsage` 有值，如 500） | `/api/usage` | `359 / 500 次`，环里显示已用次数 |
| 金额制（`usage`） | 新计划、团队 / 企业账号 | `/api/usage-summary`（单位：美分） | `$16.72 / $20.00`，环里显示百分比 |

选择顺序：先请求 `/api/usage`；如果它给出了大于 0 的次数上限，就用次数制；否则使用 `/api/usage-summary` 的金额额度；两者都没有有效数据时才报「响应异常」。**不会再假设上限是 500。**

## 没有固定上限的账号

`isUnlimited` 为真，或接口没有给出额度时，应用不显示进度、剩余和「预计用完」，只显示已用量（如 `$16.72 · 无上限`），也不会触发阈值通知。

## 套餐标签

`membershipType` 与 `limitType` 组合成标签，例如 `Pro · 个人额度`、`Team · 团队额度`，显示在浮窗卡片与概览页。

## 精确的重置时间

- 优先使用 `/api/usage-summary` 的 `billingCycleEnd`（精确到秒），按本机时区显示，精确到分钟：`10/16 10:24 重置 · 还剩 12时5分`。
- 接口没返回时，退回「周期开始时间 + 1 个月」推算。
- 倒计时格式：大于 1 天显示 `x天y时`，大于 1 小时显示 `x时y分`，其余 `x分` / `不到1分`。

## 账号隔离

- 账号标识使用 Cursor 登录的 WorkOS 用户 ID。
- 每条明细都带账号；列表、统计、图表、模型筛选都只读取当前账号的明细。
- 切换账号时，旧账号的用量、邮箱、已通知的阈值会立即清除，不会混在一起；备份导出仍包含所有账号。
- 数据库 schema v2 升级时会清除旧版本无账号标记的明细，并在首次刷新时重新同步当前账号。
- DeepSeek 账单暂未按账号隔离（以 API Key / 平台登录为准）。
