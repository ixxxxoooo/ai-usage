# 账单体验与账号隔离（v1.1.0）

> 作者：ixxxxoooo

## 需求
1. 两个账单页提供「在官网查看」。
2. 模型下拉过长，加滚动条。
3. 柱状图悬停显示文字与数量。
4. 说明并支持非 500 次的 Cursor 账号（团队 / 新计划）。
5. 切换账号后明细不能混在一起。
6. 重置倒计时精确到时分。
7. 点击浮窗两张卡片打开主窗口对应页面。

## 实现
- `internal/gui/widgets.go`：`linkButton`、`clickableCard`、`scrollSelect`（限高 260 + 滚动条）。
- `internal/gui/charts.go`：`barTip` 即时气泡。
- `internal/model`：`CursorUsage` 双口径（次数 / 金额），`CycleEndAt`、`HasCap`。
- `internal/provider/cursor`：`ParseSummary`、`FetchUsage` 合并两个接口。
- `internal/store`：schema v2，明细加 `account` 列，按账号查询。
- `internal/service`：切换账号清空旧状态、同步按账号增量。
- `internal/util.FormatCountdown`：分钟级倒计时。

## 测试
- 单元：model / util / cursor / store / service。
- 界面（headless）：下拉限高与滚动、悬停气泡、官网链接打开、卡片点击跳转、金额制浮窗。
